# Character sheet prompt

The bundled **Official Character Reference Sheet** template is from
[ZeroLu/awesome-gpt-image](https://github.com/ZeroLu/awesome-gpt-image#official-character-reference-sheet),
a collection of GPT Image 2 and GPT Image 2.5 prompts. The entry credits
OpenNana and [@MANISH1027512](https://x.com/MANISH1027512).
Source and license checked on 2026-10-05.

The original template is preserved in `lib/character-sheet.mjs`. Scene Studio appends
the user's character description, consistency requirements, style and reference roles.
